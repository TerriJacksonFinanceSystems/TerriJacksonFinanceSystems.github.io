Control principle: technical validity is not the same as accounting accuracy. FP&A reconciles dashboard output to approved source controls before relying on it for management analysis.

How to read this register

The left-hand block defines the process step, output/control, activity type and prototype boundary. The right-hand block is a deliberately distinct RACI Matrix, making ownership and hand-offs visible for every process step.

Design principle: every step has populated R, A, C and I roles, and roles are not duplicated across R/A/C within the same step.
